### Authoring or modifying a skill

**You own the skill's voice.**

1. Use the {{skill_authoring}} skill for the mechanics and the **writing-for-agents** skill ([`../../writing-for-agents/SKILL.md`](../../writing-for-agents/SKILL.md)) for the writing.
2. Validate the skill: frontmatter has `name` and `description`, referenced files exist, cross-skill links resolve.
3. Test cases if structural. Skip if subjective.
4. Run **Opening a PR**.

Match tone to scope. A workflow you keep hitting but isn't captured → propose a new skill.

**Reply:** summary of the skill, key design decisions, validation notes.
